# AIM:
To design and develop a Library Management System using software engineering principles to manage library books, members, book issue/return operations, and maintain library records efficiently.

# SRS (Procedure):
1. Start the System:
Start the Library Management System and display the main menu with all available operations.
2. Manage Books:
Add, search, view, and update book details such as Book ID, title, author, and availability status.
Maintain the book records properly in the library database.
3. Manage Members:
Register members by entering details such as Member ID, name, department, and contact number.
Store and maintain the member information for future library transactions.
4. Issue Books:
Verify the member and check whether the requested book is available before issuing it.
Record the issue date and due date, then change the book status to Issued.
5. Return Books:
Verify the issued book and member details when a book is returned.
Record the return date and update the book status to Available.
6. Display and Search Records:
Allow the librarian to search and display book, member, and transaction details whenever required.
Ensure that all records are updated correctly after every issue and return transaction.
7. Stop the System:
Continue the selected operations until the user chooses the Exit option.
Save or maintain the updated records and terminate the Library Management System.
